## Telangana Tourism Dashboard using Power BI
## Project Overview
This project presents an interactive Power BI dashboard built to analyze Telangana Tourism data from 2016 to 2019. The dashboard provides meaningful insights into visitor trends, district performance, seasonal patterns, and tourism growth to support data-driven decision-making.

The project demonstrates the complete Business Intelligence workflow including data preparation, data modeling, DAX calculations, and dashboard development.

## Objectives
Analyze domestic and foreign tourist visits
Compare district-wise tourism performance
Identify top and bottom performing districts
Monitor yearly and monthly visitor trends
Generate actionable tourism insights
